ÉLEVAGE DRAGODINDES - Dofus 3.5 (outil interne local) - v2

Lancer : double-clique sur index.html (aucune installation, aucun serveur).
Vérifier le calcul : ouvre tests.html (ou `node tests.js`).

Fichiers
- index.html : structure et textes des onglets
- style.css  : apparence (thème sombre/clair, impression)
- data.js    : données du jeu (générations, jauges, carburants, serveurs...) -> à modifier si Ankama change quelque chose
- calc.js    : calcul PUR (chance de génération cible, profit, parseur de prix "250k", "1,5M")
- store.js   : sauvegarde navigateur, migration v1->v2, export/import JSON, import par collage
- app.js     : interface
- tests.js / tests.html : tests automatiques de calc.js

Prix HDV
- Aucune source publique ne donne les prix HDV par serveur : tu les saisis toi-même (onglet Rentabilité).
- Formats acceptés : 250000, 250 000, 250k, 1,5M, 1.200.000.
- Chaque prix est daté (badge "⏱" au-delà de 7 jours).
- Les prix sont dans le navigateur (localStorage) : utilise toujours le même, et EXPORTE de temps en temps (bouton "Exporter tout (JSON)").
- La démo (prix fictifs) n'écrit jamais dans tes vrais prix.
